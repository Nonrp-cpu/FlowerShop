Гайд по GIT

Базовые команды

# Добавить все изменения
git add .

# Добавить конкретный файл
git add index.html

# Закоммитить
git commit -m "Описание изменений"

# Отправить на GitHub
git push

# Скачать изменения с GitHub
git pull

Статус и история

# Посмотреть статус
git status

# Посмотреть что изменилось
git diff

# История коммитов
git log

# История в одну строку
git log --oneline

Отмена и откат

# Отменить изменения в файле
git checkout -- file.html

# Убрать файл из индекса
git reset HEAD file.html

# Откатить последний коммит (мягко)
git reset --soft HEAD~1

# Откатить последний коммит (жестко - удаляет изменения!)
git reset --hard HEAD~1

# Отменить последний push
git revert HEAD

Ветки

# Посмотреть все ветки
git branch -a

# Создать новую ветку
git branch feature

# Переключиться на ветку
git checkout feature

# Создать и переключиться
git checkout -b feature

# Слить ветку в текущую
git merge feature

# Удалить ветку
git branch -d feature
